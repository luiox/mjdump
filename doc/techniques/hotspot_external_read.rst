HotSpot 外部读取与 SA 相关技术
==============================

服务性数据与外部读取
--------------------

HotSpot 为诊断、调试和服务性工具维护了大量运行时结构：类加载器数据、
``Klass``\ 层次、常量池、方法元数据、代码缓存和 VM 结构描述。SA
（Serviceability Agent）利用这些信息建立对目标 VM 内部状态的解释；外部读取
技术则在进程外读取同类信息，并自行处理地址空间、结构布局和一致性。

两者的共同目标是解释 VM 内存，差异在于运行环境、可用接口和一致性保证。
它们都不是 JVM 规范承诺的 classfile 导出接口。

典型读取链路
------------

.. code-block:: text

   目标进程地址空间
     -> VM 映像和结构描述
     -> 类加载器数据或类字典
     -> Klass/InstanceKlass
     -> 常量池与方法元数据
     -> 可能存在的 classfile 缓存

前半段主要解决「有哪些类、它们如何关联」；最后一步才解决「是否还有可复制
的完整输入 classfile」。这两类问题必须分开评估。

.. _techniques-hotspot-external-read-layers:

三种恢复层次
------------

.. list-table::
   :header-rows: 1

   * - 层次
     - 可得到的信息
     - 是否等价于原始 classfile
   * - 身份层
     - 类名、加载器关系、模块或类图
     - 否
   * - 结构层
     - 常量池、方法、字段、已解析元数据
     - 通常否
   * - 字节层
     - 完整 classfile 缓冲区或等价缓存
     - 可能，但取决于来源

结构层可以用于静态分析、inventory 或辅助重建，但「重建出一个可解析 class」
与「保留原始 classfile」是不同目标。重建会丢失属性顺序、未知属性、原始
常量池布局和输入时的编码细节，还可能无法表达运行时已经发生的变换。

原始 bytes 的来源问题
---------------------

完整 bytes 只有在 VM 或相关组件仍保留输入类文件、变换副本、重定义缓存或
其他可追溯载荷时才能直接获得。缓存存在性会受 VM 实现、类定义方式、重转换、
内存回收和运行时策略影响。

因此，外部读取的正确技术模型是「发现一个具体的字节来源并证明其边界」，
而不是假设 ``InstanceKlass`` 天然携带原始 classfile。不存在可信来源时，
identity/structure 结果仍有价值，但应保持在其自身层次。

.. _techniques-hotspot-external-read-tables:

VM 结构描述表
-------------

SA 导出表（``gHotSpotVMStructs`` / ``gHotSpotVMTypes`` /
``gHotSpotVMIntConstants`` / ``gHotSpotVMLongConstants``）是外部读取可用的
唯一官方布局描述：条目给出类型名、字段名、偏移与静态地址。读取器应优先从
导出表解析布局，特征扫描只作为符号被 strip 时的回退，且任何推断（如相邻
字段推断 hidden slot）都必须在输出中显式标注。

一致性与安全边界
----------------

外部读取面对的 VM 可能持续加载、卸载、编译和修改元数据。地址有效性、对象
生命周期、指针解引用和数组长度都需要在一致性窗口内判断。暂停进程能减少
竞态，但会改变目标时序；不暂停则需要容忍重试、局部不一致和不可读节点。

结构布局还受到指针压缩、对象对齐、GC、模块化、符号导出策略和 VM build
选项影响。任何读取器都应将「结构解释失败」视为正常技术边界，而非可由猜测
偏移解决的异常。

可观测面
--------

进程外服务性技术可能涉及进程句柄、内存读取、调试权限、暂停窗口和对 VM
映像数据的解析。这些行为与 agent 路径的可见性不同，但不等于不可观察。选择
外部读取通常是为了降低对目标 VM 内部的直接改动，而不是为了获得无条件的
隐蔽性。

与其他路径的关系
----------------

外部读取擅长只读 inventory 和 VM 结构解释；类文件变换事件擅长获得定义时的
完整载荷；方法级查询擅长观察局部 code array。将三者组合时，应保留每项数据
的来源层次，避免用结构层结果覆盖字节层事实，或用一次运行时观察推导所有
加载器和所有类版本。
